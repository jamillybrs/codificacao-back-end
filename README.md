#  Desenvolvimento Back-End com Node.js & Express

Bem-vindo ao meu repositório de estudos focado em **Desenvolvimento Back-End**! Este projeto tem como objetivo organizar e documentar o meu aprendizado, códigos-fonte, rotas e projetos práticos utilizando o ecossistema do **JavaScript** no lado do servidor.

---

##  Objetivos

- **Dominar o ecossistema Node.js:** Compreender o funcionamento do Node.js, Event Loop, assincronismo e gerenciamento de pacotes.
- **Construção de APIs RESTful:** Criar APIs bem estruturadas, escaláveis e funcionais utilizando o **Express**.
- **Boas Práticas de Código:** Aplicar conceitos de código limpo (*Clean Code*), tratamento de exceções, organização em camadas (Controllers, Services, Repositories) e segurança.
- **Versionamento & Deploy:** Praticar comandos de **Git/GitHub** para controle de versão e preparar aplicações para ambiente de produção.

---

##  Tecnologias Utilizadas

* **[Node.js](https://nodejs.org/):** Ambiente de execução JavaScript no servidor.
* **[Express](https://expressjs.com/):** Framework web rápido e minimalista para construção de rotas e middlewares.
* **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Linguagem principal utilizada para o desenvolvimento de toda a regra de negócio.
* **[NPM](https://www.npmjs.com/):** Gerenciador de pacotes para instalação de dependências e execução de scripts.
* **[Git](https://git-scm.com/) & [GitHub](https://github.com/):** Controle de versão e hospedagem do repositório de código.

---

## Tópicos de Estudo

- [x] **Fundamentos de Node.js:** Módulos (`CommonJS` e `ES Modules`), variáveis de ambiente e manipulação de arquivos.
- [x] **Gerenciamento de Pacotes (NPM):** Instalação de dependências, `package.json`, `package-lock.json` e scripts customizados.
- [x] **Arquitetura Web e HTTP:** Requisições, respostas, verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`), status codes e headers.
- [ ] **Rotas e Middlewares no Express:** Captura de parâmetros (`query`, `params`, `body`), validações e tratamento de erros globais.
- [ ] **Modelagem e Persistência de Dados:** Integração com banco de dados (SQL / NoSQL) e uso de ORMs/Query Builders.
- [ ] **Autenticação e Segurança:** Implementação de tokens JWT, hashing de senhas com Bcrypt e suporte a CORS.
