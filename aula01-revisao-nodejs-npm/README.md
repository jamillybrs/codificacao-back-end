Nesta aula de revisão de Node.js e NPM, realizamos a configuração inicial de um projeto Node e o desenvolvimento de um script prático para ler informações do sistema operacional.

Resumo das atividades realizadas:

Verificação do Ambiente: Checagem das versões instaladas do Node.js (node -v) e do NPM (npm -v) no terminal.

Inicialização do Projeto: Criação do arquivo de configuração do projeto (package.json) utilizando o comando npm init -y.

Estruturação de Arquivos: Organização do repositório com os arquivos diagnostico.js, package.json e README.md.

Manipulação de Módulos Nativos: Importação e uso do módulo nativo os para coletar dados do sistema.

Criação do Script de Diagnóstico (diagnostico.js): Desenvolvimento de um código que obtém e exibe no console:

Arquitetura/plataforma do sistema operacional.

Quantidade de memória RAM total e disponível (convertida para GB).

Informações do processador (quantidade de cores, modelo e velocidade em MHz).
