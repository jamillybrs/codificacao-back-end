# Aula 06 - Servidor Web com Node.js

##Conteúdo da aula

Nesta aula foi desenvolvido um servidor web utilizando o módulo nativo `http` do Node.js.

O objetivo foi compreender como criar um servidor HTTP, receber requisições, identificar rotas e enviar respostas para o cliente.
