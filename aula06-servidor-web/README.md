#  Aula 06 — Servidor Web com Node.js

## Sobre a aula

Nesta aula foi desenvolvido um **servidor web utilizando Node.js e o módulo nativo `http`**.

O objetivo principal foi compreender os fundamentos de um servidor HTTP, desde o recebimento de requisições até o envio de respostas, trabalhando também com **rotas, códigos de status HTTP, JSON e cabeçalhos de segurança**.

---

##  Objetivos

Durante a atividade foram trabalhados os seguintes conceitos:

- Criação de um servidor HTTP com Node.js;
- Utilização do módulo nativo `http`;
- Recebimento e análise de requisições;
- Identificação de métodos HTTP e URLs;
- Criação de rotas;
- Utilização de códigos de status HTTP;
- Retorno de dados no formato JSON;
- Tratamento de rotas inexistentes;
- Configuração de cabeçalhos HTTP;
- Implementação de uma rota de verificação de status;
- Execução do servidor na porta `3000`.

---

##  Tecnologias utilizadas

- **Node.js**
- **JavaScript**
- **HTTP**
- **JSON**
- **ES Modules**
